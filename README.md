# Portal Estudante — CART

Primeira estrutura-base do Portal Estudante.

## Tecnologias
- HTML5
- CSS3
- JavaScript

## Como testar
Abra a pasta no Visual Studio Code e execute `index.html` no navegador.
O projeto também pode ser usado com a extensão Live Server.

## Imagens
Coloque a logo real em `assets/img/logo-cart.png` e a foto da equipe em `assets/img/equipe-cart.jpg`.
Na próxima etapa, o código poderá ser ajustado para exibir essas imagens.
